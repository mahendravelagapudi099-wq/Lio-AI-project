# Deprecated Files

This folder contains files that have been identified as unused, legacy, or temporary during the Codebase Cleanup.

## Why are files here?

- **Unused:** Not imported by any core module.
- **Legacy:** Old versions of scripts or GUI.
- **Test:** One-off test scripts that are no longer needed.

## Restoration

If you find that a file here is actually needed:

1. Move it back to its original location.
2. Update the documentation to explain its usage.
